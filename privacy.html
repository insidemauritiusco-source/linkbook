LinkBook — Privacy Notice

Beta version — 8 November 2026. This notice describes how the current LinkBook web app handles user information. It should be reviewed by the platform operator before a wider public launch.

Information handled

LinkBook accounts may contain your email address, phone number if phone sign-in is enabled, display name, bio, location, profile image, authentication data, account settings and sign-in metadata. When you use LinkBook, the app stores posts, comments, reactions, saved posts, friend requests, messages, reports and live interaction records.

Who can see content

Posts and member profiles may be seen by other signed-in members. Messages are intended to be accessible only to their participants. Uploaded post and profile media currently use a public-readable storage bucket: anyone with the file URL can access that media. Do not upload sensitive files or private photos. Blocking can hide profiles and posts and prevent new friend requests or messages, but it does not erase earlier copies or downloads.

Service providers

LinkBook uses GitHub Pages for the web interface and Supabase for authentication, data storage, uploads and real-time features. Those services may process technical logs and information needed to deliver and secure the app. Browser-local demo content is stored only on the device used for the demo.

Data export and deletion

Signed-in members can open Safety & privacy to download a JSON export of selected profile, post, comment, message and activity records, subject to the current per-section export limits. Media URLs in exports are not downloaded as files. The protected account deletion action deletes the authenticated account and its associated records, and attempts to remove its uploaded files. Data already copied by others may remain outside the app; provider backups and logs follow applicable retention practices.

Security and limits

LinkBook uses Supabase authentication and database access rules. The beta currently does not provide a guarantee of end-to-end message encryption, complete removal of every backup, or large-scale moderation coverage. Live video uses peer-to-peer connections with other viewers, so network connectivity information may be exposed as part of WebRTC negotiation.

Voice and video calls (beta)

Accepted friends may start one-to-one voice or video calls using WebRTC while both have LinkBook open. Your browser asks for microphone and camera permission before media is sent. LinkBook stores call setup information, caller/recipient identifiers, call type and technical signaling messages in Supabase to connect participants. The current prototype does not intentionally record call audio or video, but network connection details can be exposed during peer-to-peer setup, and call setup records are not yet subject to a defined automatic deletion schedule. Call quality, incoming ringing and connectivity are not guaranteed on every network or in the background. Only use this beta calling feature if you accept these limitations.

Questions and rights

Use the in-app reporting and account controls. Platform owner contact details and any required regional privacy notices should be completed before a broad public release.
